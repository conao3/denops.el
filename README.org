* denops.el

Emacs client for [[https://github.com/vim-denops/denops.vim][denops.vim]], enabling you to use denops plugins from Emacs.

[[https://github.com/vim-denops/denops.vim][Denops]] is an ecosystem for creating Vim/Neovim plugins using [[https://deno.land/][Deno]]. This package provides an Emacs interface to communicate with the denops server, allowing you to leverage denops plugins in your Emacs workflow.

** Requirements

- Emacs 26.1 or later
- [[https://deno.land/][Deno]] runtime
- [[https://github.com/vim-denops/denops.vim][denops.vim]] (for the server component)

** Installation

Clone this repository and add it to your load-path:

#+begin_src elisp
(add-to-list 'load-path "/path/to/denops.el")
(require 'denops)
#+end_src

** Usage

*** Starting the Denops Server

First, start the denops server in a terminal:

#+begin_src bash
deno run -A /path/to/denops.vim/denops/@denops-private/cli.ts --port 50635
#+end_src

*** Connecting from Emacs

Connect to the running server:

#+begin_src elisp
M-x denops-start-server
#+end_src

*** Calling Denops Plugins

Use ~denops--send-notify~ to invoke denops plugin functions:

#+begin_src elisp
(denops--send-notify "invoke" "dispatch" ["plugin-name" "method" [args]])
#+end_src

Example:

#+begin_src elisp
(denops--send-notify "invoke" "dispatch" ["helloworld" "maze" []])
#+end_src
